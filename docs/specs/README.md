# Schema narratives

Human-readable notes for the JSON schemas. The contracts themselves are in `data/schemas/` (art-side schemas in
`data/art/_schema/`); do not add runtime JSON here.

Only `card-schema.md` describes a schema with live data (`data/schemas/codex-schema.json`). The rest describe systems
with no data yet (maps, players, alliances, stores, ...), written before the current scope; treat them as drafts and
re-check them against the schema when that system is built. See [STATUS.md](../STATUS.md).
