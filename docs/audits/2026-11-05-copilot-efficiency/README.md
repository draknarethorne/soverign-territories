# Copilot collaboration efficiency review - Nov 5, 2026

**Status:** assessment and proposal, not an instruction/tooling rollout.

## Bottom line

The largest opportunity is **fewer unnecessary model round trips carrying
large context**, not shorter final answers or skipping verification.
We already have strong launchers and safety rules, but repeatedly rebuild
context, improvise acceptance commands and maintain overlapping narrative
documents. On-demand skills can package repeated procedures; deterministic
commands should prove mechanical facts. Neither replaces judgment or tests.

## Recommended sequence

1. Keep the newly adopted execution spine; stop recreating its schedule in
   every domain document.
2. Package **milestone handoff**, **feedback/plan transfer** and **long-run
   acceptance** as small on-demand skills around existing launchers.
3. Implement existing day-close D4 as a read-only mechanical guard before
   inventing another management command.
4. Add a privacy-preserving local usage summary only if the repeat need
   justifies it; use measured calls/cache/token categories, not guessed bills.
5. Test a shorter always-on instruction entry point in a fresh session,
   retaining critical boundaries and links. Compare quality as well as size.
6. Use milestone-sized sessions and event-driven monitoring; leave the
   heavy job running independently of model conversation.

These are proposals, not new skill files, settings changes, models or
commands implemented by this assessment. The already approved milestone
agreement remains in force. Main-run acceptance has priority over this
bounded read-only/documentation companion.

## Scope and decisions

The user requests an in-depth report series on usage, credits, collaboration,
skills, agreements, sessions, tools, launchers and unattended work. A
clarification form could not obtain a response before departure. Conservative
defaults: this session plus available recent repository history; telemetry
only, no billing access; write findings/proposals without an additional
runtime/instruction/skill rollout.

The available current session spans Oct 29-Nov 5. Recent-session searches
did not establish a comparable dataset for this repository; no unrelated
repository/account sessions were incorporated. This is a strong case study,
not a representative benchmark of every user's or every model's performance.

No raw conversations, credentials, protected prompts, account identifiers
or source-image data are exported here. No session/log/cache is deleted.
The [execution spine](../../plans/2026-11-05-priority-reset.md#execution-spine)
owns selection and implementation of any accepted recommendations.
