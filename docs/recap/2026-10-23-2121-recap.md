## What was good

- Looking at the actual outputs exposed failures that counts could hide:
  reaction-icon coverage did not imply logo, hair-bubble or caption coverage.
- Kept masks/candidates visible and nonselected, and preserved all source
  bytes/state. A wider mask is an experiment, not permission to trust it.
- Reused immutable per-photo reports from the GUI without another image cache.
  The explicit ambiguity state avoids inventing an authoritative run.
- Reused saved Review evidence for GUI previews instead of rescanning faces or
  rebuilding live reports. Historical previews are not action authority.

## What was bad

- A corner logo can mostly disappear while its replacement is a conspicuous
  texture smear. A pixel-change score would reward the wrong thing.
- Hair guards preserve identity-critical content but leave the overlay across
  it untouched. Erasing only the ends of a bubble is not satisfactory cleanup.
- Generic stroke heuristics can touch real image detail. Their false positives
  are a reason to retain rejection, not loosen automatic acceptance.
- Comparison evidence is expensive: the new run adds about 1.99 GB. Full
  evidence-index verification took about 99 seconds for the saved Review
  preview, so repeated Artist publication was deferred rather than hiding
  the cost.
- The first replay was nested too deeply for Windows filename limits.
  Publication failed safely; a shorter root succeeded without source changes.
- I mishandled a temporary verification snapshot while collecting evidence.
  Final proof was recomputed against the untouched pre-v8 baseline, not that
  damaged scratch file: 113 live input hashes/sizes/mtimes and both state files
  still match. Verification helpers must read baselines, never recreate them.
