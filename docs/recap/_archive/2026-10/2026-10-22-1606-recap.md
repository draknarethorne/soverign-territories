## What each kind of command does

- **Gallery generation** publishes a snapshot and derived report assets; it
  does not apply staged library actions.
- **Action validate/preview** checks downloaded decisions without moving photos.
- **Action apply/undo** executes or reverses the explicit manifest through its
  backed-up transaction. It is not a request to globally self-heal the library.
- **Ordinary likeness/library maintenance** is a separate shared-engine path:
  freeze evidence, consider incoming/Review candidates and policy-eligible
  affected identities, propose bounded changes, then apply only under the
  appropriate authorization. It is not an unrestricted recursive reshuffle.
- **Clean rebase/reset** rebuilds from its defined source snapshot. It is not
  the next step after every manual test and can replace the working scenario.
  Never use it casually to test no-reset healing or assume it preserves newly
  recorded decisions; non-cast permanent exclusions currently block unsupported
  clean-rebuild migration.

For the proposed test of rejecting photos from several Models: ordinary
Reject returns those photos to Various without a lasting exclusion;

identities. Discuss the expected policy/affected scope, preview the subsequent
