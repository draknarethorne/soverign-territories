# New-PC rehearsal and other-machine handoff

Coordinate the independent new-PC SIMPLE rehearsal, the still-active
other-machine work, and any verified artifact transfers. The user reports
that a process on the other machine is still active; its identity, state and
completion are not independently known here. Do not interrupt it or start a
competing writer.

The [daily recap](../../recap/2026-11-21-new-pc-recap.md) records the new-PC
result. The [planning agreement](../../plans/README.md) and its execution
spine retain task ownership. Messages live in `messages/`; follow the
[collaboration protocol](../README.md) and add a new file for each response.
