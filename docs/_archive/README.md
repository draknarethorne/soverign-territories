# Archive Index

This folder holds superseded and historical project documents, not disposable
trash. Archival alone never authorizes a purge.
See the `_archive` convention in `docs/README.md`: nothing here is current, and it is not read as documentation
unless explicitly requested.

## Naming convention

- `*-SUPERSEDED.md` = replaced by newer canonical documentation.
- `*-HISTORICAL.md` = retained as milestone/history reference.
